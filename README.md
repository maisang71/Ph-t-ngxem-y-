Đây là mã nguồn Website chuyên nghiệp chuẩn **Giao diện 5.0** dành cho cửa hàng **Mai Sang**, chuyên mua bán xe máy và cung cấp phụ tùng chính hãng. Dự án được phát triển và tối ưu hóa để chạy và lập trình trực tiếp trên các thiết bị di động thông qua ứng dụng **Acode** hoặc **Trebedit**.

## ✨ Tính Năng Nổi Bật

- 🎨 **Giao diện 5.0 Hiện Đại:** Thiết kế chuẩn UI/UX thương mại điện tử, thân thiện với mọi kích thước màn hình (Responsive Design).
- 💾 **Quản Trị Đăng Bài Trực Tiếp (LocalStorage):** Không cần cài đặt cơ sở dữ liệu phức tạp. Quản trị viên có thể thêm xe máy và phụ tùng mới trực tiếp trên web, dữ liệu được lưu cục bộ trên trình duyệt.
- 🛡️ **Xử Lý Lỗi Ảnh Thông Minh (Fallback Image):** Tự động chuyển về ảnh mặc định dự phòng nếu link ảnh (từ Facebook hoặc nguồn ngoài) bị lỗi hoặc hết hạn.
- 📞 **Nút Tương Tác Nhanh:** Tích hợp nút gọi điện nổi và kết nối chat Zalo trực tiếp.
- ⚡ **Siêu Nhẹ & Mượt Mà:** Toàn bộ ứng dụng được gói gọn trong một file `index.html` duy nhất (Single Page Application HTML/CSS/JS).

## 🛠️ Công Nghệ Sử Dụng

- **HTML5 & CSS3:** Xây dựng cấu trúc và phong cách giao diện.
- **Vanilla JavaScript:** Xử lý logic thêm bài viết và quản lý dữ liệu DOM.
- **LocalStorage API:** Lưu trữ dữ liệu sản phẩm.
- **Google Fonts (Poppins):** Font chữ hiện đại, dễ đọc.
- **FontAwesome 6.4:** Hệ thống icon vector đa dạng.

## 🚀 Hướng Dẫn Cài Đặt & Sử Dụng

Vì đây là dự án tĩnh, bạn có thể chạy nó ở bất cứ đâu!

### 📱 Trên Điện Thoại (Acode / Trebedit)
1. Clone repository này về hoặc tải file `index.html`.
2. Mở ứng dụng **Acode** (hoặc **Trebedit**) trên Android.
3. Mở file `index.html`.
4. Nhấn nút **Play / Preview** để chạy website.
